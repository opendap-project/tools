# Toolkit image requirements

Requirements TK-001, TK-009, TK-010 and TK-011 (cli repository) apply to every toolkit repository.

This repository has no requirements of its own yet. Context: [RFC 0008](https://github.com/opendap-project/rfcs/blob/main/text/0008-repository-restructure.md), which moved these tools here from blackbird-os `build/` and system `scripts/`.
