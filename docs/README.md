# Documentation

| Folder | Contents |
|---|---|
| [`requirements/`](requirements/) | What the tools must achieve. Each requirement has an ID, a priority (**must** / **should**) and a status. Their source is [`requirements.toml`](requirements/requirements.toml); the README is rendered from it with `odw req render`. |

Each domain folder keeps its specifications beside its engines (`<folder>/docs/specs/`); the [root README](../README.md) lists the folders.

Only information confirmed by the maintainers is recorded here. Earlier experiments are not a source.

**Requirement status:** *Confirmed* (agreed, build on it) · *Draft* (agreed intent, wording or detail still open).
